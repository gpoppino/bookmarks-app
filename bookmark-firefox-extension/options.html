Bookmarks App

Conectá Firefox con tu servidor para guardar páginas desde la barra de herramientas.

La dirección que expone la API, sin /api/bookmarks. Para desarrollo: http://127.0.0.1:8000. Fuera del equipo local se requiere HTTPS.

Crealo en /docs del backend: iniciá sesión y ejecutá POST /api/auth/bot-tokens. Se muestra una sola vez. Un token por navegador permite revocarlos por separado.

Datos enviados y permisos

Al pulsar Guardar bookmark, se envían la URL y las etiquetas al backend configurado, junto con el token para autenticar el pedido. No se envía el historial ni el contenido de otras pestañas.

Firefox solicita acceso al host del backend al guardar la configuración. El permiso abarca todos sus puertos; la extensión usa únicamente la URL configurada.

El token se guarda en el perfil local de Firefox, sin sincronización ni cifrado adicional. Borrar la configuración no revoca el token: revocalo en el backend si ya no lo vas a usar.

El backend obtiene los metadatos de la página y puede usar OpenAI para sugerir etiquetas si esa función está habilitada en el servidor.
